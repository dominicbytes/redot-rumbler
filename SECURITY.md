# Security policy

Treat the entire Rumble Live Stream API URL and any returned `stream_key` as credentials.

Never submit either value in a public issue, source file, scene/resource, project setting, log, screenshot, fixture, workbook, or crash report. If exposure is possible, reset the URL in Rumble before investigating local cleanup.

For a vulnerability in Redot Rumbler, use a private GitHub Security Advisory after the standalone repository is created. Describe the behavior with synthetic values only. Do not attach private stream responses or user chat data.
